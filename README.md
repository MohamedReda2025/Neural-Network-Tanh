This repository contains the solution for the Computational Neuroscience assignment.

- Implement the forward pass of the neural network from the lecture examples.
- Use the `tanh` activation function instead of sigmoid.
- Initialize weights randomly from the interval `[-0.5, 0.5]`.
- Set biases to `b1 = 0.5` and `b2 = 0.7`.
- Print the final outputs of the network.
- 
The script uses `numpy` to generate random weights and calculate the hyperbolic tangent (`tanh`). It strictly follows the mathematical steps discussed in the lecture for computing the net input and the activated output for both the hidden and output layers.
